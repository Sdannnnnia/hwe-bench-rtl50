## 原始 HWE 题面

## Description
In CVA6, the memory management unit (MMU) translates virtual addresses for load and store requests from the load/store unit (LSU). When an LSU request already carries a valid misaligned-address exception, that request should be treated as faulting immediately. Instead, the load/store translation path can still start data-side address translation and produce a page-table memory access for the same request.

## Expected Behavior
If the LSU presents a load or store together with a valid misaligned-address exception, the MMU must return the misaligned exception for that access and stop the translation flow for that request. The same access must not trigger a data-side translation lookup or any page-table memory request.

## Actual Behavior
With load/store address translation enabled, a misaligned LSU request can still initiate translation-side activity and generate an observable page-table memory access even though the request is already being reported as misaligned.

## Affected Function
The affected functionality is the MMU load/store address-translation path, specifically the gating between LSU requests that already carry an exception and the data-side translation/page-table access path.

## Trigger Condition
The bug is triggered when load/store virtual-address translation is enabled and the LSU submits a load or store request that already has a valid misaligned-address exception.
